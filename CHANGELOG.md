# Список изменений

## BETA 9.1 (сборка на основе BETA 9 от DeaDSoftWare)

### 🛠 Восстановление утерянного кода

- **Восстановлен модуль `mobs.mpsrc` (весь ИИ мобов)** — оригинальный исходник
  был утерян; модуль переписан с нуля по байткоду собранного `CAVE.jar`:
  - гравитация и коллизии через модуль `phy`, прыжки через препятствия;
  - мирные мобы бродят случайно, враждебные (зомби, крипер, паук, свинозомби)
    преследуют игрока с агро-радиусом 240 px;
  - атака игрока при касании (крипер — усиленная), плавание в воде и лаве;
  - смерть с дропом лута: гнилая плоть, свинина, шерсть, перо + яйцо, порох,
    говядина + кожа, нить + паучий глаз, золотой самородок;
  - стрижка овец (использованием), отрастание шерсти со временем;
  - функции урона от взрывов (`coll_boom`, `mob_coll_boom`).
- В `vars.mpsrc` возвращены объявления записей `R_0`/`R_1` и массивов
  `mob`/`mob_info` (в имевшихся исходниках они отсутствовали — проект не
  собирался).
- Устаревший стаб `mob.mpsrc` очищен, `mobs.mpsrc` подключён в `CAVE.mpproj`.

### 🔴 Исправлены критические баги

- **Сохранение позиции игрока**: в `saveworld` дважды писалась X-координата
  вместо X и Y — после загрузки игрок оказывался под землёй/в камне.
- **Парсер `FALSE`**: `strToBool('FALSE')` возвращал `true` — все
  отключающие настройки в `autoexec.cfg` фактически работали наоборот.
- **Печи не сбрасывались** между мирами и при загрузке — 32 слота
  «заканчивались» и новые печи становилось невозможно поставить.
  Добавлен `furnace.resetData`.
- **Краш при чтении табличек**: неинициализированный счётчик строк —
  повторное открытие таблички выводило за границы массива (краш мидлета).
- **Меню загрузки сейвов**: при отсутствии сейвов счётчик выбранного мира
  инкрементировался бесконечно (уход за границы массива).
- **Деление на ноль** в расчёте FPS при кадрах короче 1 мс.

### 🟠 Исправлены логические баги

- **Урон оружия**: тип предмета проверялся по количеству в стаке —
  инструменты наносили почти нулевой урон.
- **Крафт при полном инвентаре**: остаток выпадал дропом с ID = количеству
  («блок 3» = земля) вместо самого предмета.
- **Поплавок удочки** поднимался по воде на ~150 блоков за время клёва.
- **Портал в Нижний мир** заливался адским камнем при генерации
  (условие `or` вместо `and`).
- Удалены недостижимые дубли веток в destroy-функциях (id 62 ×2, id 95 ×3).
- `useItem` продолжал выполнение с пустым слотом руки.
- Команда `SET_CANV_TEX` без `else` «съедала» аргументы следующей команды.
- Переполнение массива корней дисков в `getroot` (при >16 дисков).
- Редкие отрицательные значения ГПСЧ (`abs(-2147483648)`) — заменено на
  сброс старшего бита.
- **Настройка `GET_DRP` заработала**: переменная объявлялась в двух модулях
  и никогда не проверялась; теперь подбор дропа можно отключать.
- Окно быстрого крафта закрывалось процедурой окна сундука (утечка
  графики сундука, некорректная очистка).
- **Окна ввода (сид, имя мира, таблички)**: кнопка OK не работала —
  `addCommand` вызывался после `showForm` без `repaint`. Теперь команда
  добавляется до показа формы, добавлен `repaint` и `delay` в цикле ожидания.
- Возврат корректного значения из `useItem` при пустой руке (`exit`).

### ⚡ Оптимизации производительности

- **ИИ мобов**: мобы в радиусе 20 блоков обновляются каждый кадр, дальние —
  раз в 8 кадров со сдвигом фазы (основной прирост FPS при толпе мобов).
- **Печи**: игровая логика печей обновляется не чаще 10 раз/сек (время
  печей считается по абсолютным таймстампам — корректность не страдает).
- **Свет**: пересчёт освещения раз в 2 кадра; в `light_rect`/`light_fillrect`
  добавлены ограничители координат — убраны постоянные исключения за
  границами карты.
- **Дроп**: рисуются только предметы в пределах экрана.
- **Звёзды**: рисуются только ночью (днём пропускается цикл из сотен
  вызовов ГПСЧ и `plot` на каждый кадр).
- **Кеш окрашенного шрифта**: `ReplaceImgColor` больше не создаёт новое
  изображение на каждый символ каждого кадра (жёлтый splash-текст и др.).
- **`usetools`**: `getBlockHP` кешируется в локальную переменную
  (3 вызова на кадр → 1).

### ❄️ Графика и геймплей

- **Осадки переработаны**:
  - слой снега/дождя больше не привязан к сетке блоков — плавно прокручивается
    вниз (2 px/кадр), создавая эффект настоящего падения;
  - добавлены **снежинки-частицы** (новый тип 8): до 50 штук падают над
    зимним биомом с покачиванием, «тают» при касании блока — эффект глубины.
- **Сид в меню создания мира предгенерируется** из текущего времени —
  не нужно вводить вручную (осталось только подтвердить или изменить).
- `autoexec.cfg`: `S_WEATHER`/`S_LIGHT`/`S_PARTICLES` переведены на `TRUE`
  для сохранения привычной картинки (раньше их включал баг парсера).
- Версия в углу экрана: `BETA 9.1`; `MIDlet-Version: 1.9.1`.

### 🔧 Инфраструктура сборки

- Добавлены скрипты CLI-сборки `build_units.ps1` + `build_jar.ps1`
  (MIDletPascal 3.5, mp3CC.exe): топологический порядок юнитов, упаковка
  jar с ресурсами по списку из `CAVE.mpproj`.
- Папка `classes/` обновлена свежими `.bsf`/`.class` — IDE-сборка проекта
  снова работает из коробки.
- В `libs_ref/` сохранены справочные исходники библиотек из `libs.zip`
  (включая полный исходник рантайма MidletPascal).

### ℹ️ Совместимость

- Формат сохранений не менялся (`version_map=8`) — **старые сейвы работают**.
- Генерация мира от конкретного сида изменилась (исправление ГПСЧ) —
  те же сиды теперь дают другие миры.
