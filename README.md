# CaveCraft (BETA 9.1) — J2ME

Клон Minecraft для кнопочных телефонов (Java ME / MIDP 2.0), написанный на
**MidletPascal 3.5**. Это продолжение CaveCraft BETA 9 от DeaDSoftWare:
восстановлен потерянный исходник ИИ мобов, исправлена пачка багов,
добавлены оптимизации производительности и новые эффекты.

![Версия](https://img.shields.io/badge/version-BETA%209.1-blue) ![Платформа](https://img.shields.io/badge/platform-J2ME%20MIDP%202.0-green)

## Что нового в BETA 9.1

Полный список изменений — в [CHANGELOG.md](CHANGELOG.md).

- **Восстановлен модуль `mobs.mpsrc`** (ИИ мобов) — оригинальный исходник был
  утерян, модуль переписан по байткоду из собранного jar: гравитация, прыжки,
  блуждание и преследование, атаки, дроп лута, стрижка овец.
- **Исправлены критические баги**: сохранение Y-координаты игрока,
  парсер `FALSE` в конфигах, сброс печей между мирами, краш табличек,
  деление на ноль в счётчике FPS, урон оружия и другие.
- **Оптимизации**: ИИ дальних мобов раз в 8 кадров, печи 10 Гц, пересчёт
  света через кадр, клиппинг дропа, кеш окрашенного шрифта — заметный
  прирост FPS на слабых устройствах.
- **Красивый снег и дождь**: плавное падение слоя осадков + снежинки-частицы.
- **Мелочи**: предгенерация сида в меню, рабочая кнопка OK в окнах ввода
  (сид/таблички), настройка GET_DRP и др.

Старые сохранения совместимы (формат `version_map=8` не менялся).

## Сборка

### Вариант 1: скрипты (нужен MIDletPascal 3.5)

```powershell
# путь к mp3CC.exe внутри скриптов поправьте при необходимости
powershell -ExecutionPolicy Bypass -File build_units.ps1   # юниты + главный модуль
powershell -ExecutionPolicy Bypass -File build_jar.ps1     # упаковка bin/CAVE_test.jar
```

Важно: пути сборки должны быть без кириллицы, главный модуль компилируется
в ту же папку, где лежат собранные юниты.

### Вариант 2: IDE MidletPascal

Открыть `CAVE.mpproj` и собрать проект (Sources + Resources уже настроены).

## Структура проекта

| Папка | Назначение |
|---|---|
| `src/` | исходники на MidletPascal (`.mpsrc`) |
| `res/` | ресурсы: текстуры, звуки, конфиги (`*.cfg` в cp1251) |
| `libs/` | библиотеки `Lib_*.class` (+ исходники части из них) |
| `classes/` | скомпилированные юниты (`.class` + `.bsf`) для IDE-сборки |
| `bin/` | собранные jar/jad |
| `libs_ref/` | справочные исходники библиотек из архива libs.zip |
| `CAVE.mpproj` | файл проекта MidletPascal |

## Управление

См. Help в игре. Клавиши настраиваются в `res/keyboard.cfg`,
графика/поведение — в `res/autoexec.cfg` (консольные команды MidletPascal).
